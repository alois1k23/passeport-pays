# Passeport Pays

Carte du monde sur fond noir : clique sur un pays (ou cherche-le) pour le marquer comme visité, il passe en bleu.

- Clic sur un pays : ajouter / retirer
- Barre de recherche (noms en français, accents facultatifs)
- Zoom molette / pincement, boutons + − ⟲
- Liste des pays visités, compteur et pourcentage
- Sauvegarde automatique dans le navigateur (localStorage), export / import JSON

## Lancer

Ouvrir `index.html` dans un navigateur, rien à installer. Pour l'avoir en ligne : activer GitHub Pages sur la branche `main` (Settings → Pages).

Données : [world-atlas](https://github.com/topojson/world-atlas) (Natural Earth 1:50m), noms via `i18n-iso-countries`.
